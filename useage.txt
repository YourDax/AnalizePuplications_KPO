Инструкция по работе с приложением
Данная инструкция предназначена для пользователей и описывает пошаговые действия при работе с приложением.
1. Запуск приложения
При запуске приложения на экране появляются две кнопки:
•	Работа с сотрудниками
•	Работа с физическими лицами
 
 
2. Работа с физическими лицами
При выборе раздела "Работа с физическими лицами" открывается подменю, содержащее следующие функции:
1.	Создание физического лица
2.	Добавление физического лица
3.	Редактирование физического лица
4.	Просмотр физ. лиц
5.	Удаление физического лица
 
 
2.1. Добавление физического лица
•	Нажмите кнопку "Добавление физ. лица".
•	Заполните необходимые поля для добавления нового физического лица.
•	Нажмите кнопку Сохранить, чтобы сохранить данные.
 
 
2.2. Редактирование физического лица
•	Нажмите кнопку "Редактирование физ. лица".
•	Используйте функцию поиска для выбора нужного физического лица.
•	Все поля автоматически заполнятся текущими данными.
•	Измените необходимые поля.
•	Нажмите кнопку Сохранить, чтобы сохранить изменения.
 
2.3. Просмотр физ. лиц
•	Нажмите кнопку "Просмотр физ. лиц".
•	Откроется таблица со всеми физическими лицами, доступна функция поиска.
 
 
2.4. Удаление физического лица
•	Нажмите кнопку "Удаление физ. лиц".
•	Откроется таблица с функцией поиска.
•	Выделите строку с необходимым физическим лицом и нажмите кнопку Удалить, чтобы удалить запись.
 
 
3. Работа с сотрудниками
При выборе раздела "Работа с сотрудниками" открывается подменю с функциями:
1.	Создание сотрудника
2.	Удаление сотрудника
3.	Редактирование сотрудника
4.	Просмотр сотрудников
5.	Формирование договора
 
 
3.1. Создание сотрудника
•	Нажмите кнопку "Добавление сотрудника".
•	Выберите физическое лицо по ФИО и дате рождения.
•	Заполните дополнительные поля, необходимые для создания сотрудника.
•	Нажмите кнопку Сохранить, чтобы сохранить запись.
 
 
3.2. Формирование договора
•	Нажмите кнопку "Формировать договор".
•	Выберите путь для сохранения файла.
•	После сохранения откройте созданный документ Word.
•	Проверьте данные и обеспечьте подписание документа обеими сторонами.
 
 
 
2.4. Удаление сотрудикнов
•	Нажмите кнопку "Удаление сотрудников".
•	Откроется таблица с функцией поиска.
•	Выделите строку с необходимым физическим лицом и нажмите кнопку Удалить, чтобы удалить запись.
 
 
2.2. Редактирование сотрудника
•	Нажмите кнопку "Редактирование сотрудника".
•	Используйте функцию поиска для выбора нужного сотрудника по полям: должность, ФИО, дата рождения.
•	Все поля автоматически заполнятся текущими данными.
•	Измените необходимые поля.
•	Нажмите кнопку Сохранить, чтобы сохранить изменения.
 
 
3.3. Просмотр сотрудников
•	Нажмите кнопку "Список сотрудников".
•	Откроется таблица с функцией поиска.
•	Из списка можно перейти к управлению отпусками и зарплатой.
 
 
4. Управление отпусками
При выборе раздела "Управление отпусками" открывается подменю с функциями:
1.	Добавление отпуска
2.	Удаление отпуска
3.	Редактирование отпуска
4.	Просмотр отпусков
5.	Генерация отчёта
 
 
4.1. Добавление отпуска
•	Нажмите кнопку "Добавить отпуск".
•	Выберите сотрудника по ФИО, должности и дате рождения.
•	Заполните дополнительные поля.
•	Нажмите кнопку Сохранить.
 
 
4.2. Редактирование отпуска
•	Нажмите кнопку "Редактировать отпуск".
•	Найдите отпуск с помощью поиска (ФИО сотрудника, дата начала и окончания).
•	Отредактируйте необходимые данные.
•	Нажмите кнопку Сохранить.
 

 
2.4. Удаление отпусков
•	Нажмите кнопку "Удаление отпусков".
•	Откроется таблица с функцией поиска.
•	Выделите строку с необходимым физическим лицом и нажмите кнопку Удалить, чтобы удалить запись.
 
 
4.3. Просмотр отпусков
•	Нажмите кнопку "Список отпусков".
•	Используйте поиск для просмотра информации об отпусках.
•	Из списка можно перейти к генерации отчёта.
 
 
4.4. Генерация отчёта
•	Нажмите кнопку "Генерация отчёта".
•	Выберите путь сохранения.
•	Откройте Excel файл с отчётом по отпускам.
 
 
 
5. Управление зарплатой
При выборе раздела "Управление зарплатой" открывается подменю с функциями:
1.	Добавление зарплаты
2.	Удаление зарплаты
3.	Редактирование зарплаты
4.	Просмотр зарплат
5.	Генерация отчёта
 
 
5.1. Добавление зарплаты
•	Нажмите кнопку "Добавить зарплату".
•	Выберите сотрудника по ФИО, должности и дате рождения.
•	Заполните дополнительные поля.
•	Нажмите кнопку Сохранить.
 
 
5.2. Редактирование зарплаты
•	Нажмите кнопку "Редактировать зарплату".
•	Найдите зарплату с помощью поиска (ФИО, должность, дата выплаты).
•	Отредактируйте необходимые данные.
•	Нажмите кнопку Сохранить.
 
 
2.4. Удаление зарплат
•	Нажмите кнопку "Удаление зарплат".
•	Откроется таблица с функцией поиска.
•	Выделите строку с необходимым физическим лицом и нажмите кнопку Удалить, чтобы удалить запись.
 
 
5.3. Просмотр зарплат
•	Нажмите кнопку "Список зарплат".
•	Используйте поиск для просмотра информации о зарплатах.
•	Из списка можно перейти к генерации отчёта.
 
 
5.4. Генерация отчёта
•	Нажмите кнопку "Генерация отчёта".
•	Выберите путь сохранения.
•	Откройте Excel файл с отчётом по зарплатам.
 
 
 
6. Диалоговые окна и уведомления
1.	При успешном создании записей (сотрудников, физ. лиц, отпусков, зарплат) отображается диалоговое окно с информацией об успешном сохранении.
 
2.	При успешном формировании договора или отчёта отображается уведомление об успешной операции.

 
3.	Если какое-либо поле не заполнено, окно сохранения не закроется до тех пор, пока не будут исправлены ошибки.
