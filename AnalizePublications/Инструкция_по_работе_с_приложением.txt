Инструкция по работе с приложением
Данная инструкция предназначена для пользователей и описывает пошаговые действия при работе с приложением "Система анализа публикаций".

1. Запуск приложения
При запуске приложения на экране отображается главная страница с тремя карточками:
•	Авторы
•	Публикации
•	Источники
Рис. 1 - Главная страница приложения. Отображает три карточки для навигации к основным разделам: Авторы, Публикации и Источники. Каждая карточка содержит кнопки "Просмотр" и "Поиск" для быстрого доступа к функциям.

 
2. Работа с авторами
При выборе раздела "Авторы" доступны следующие функции через меню навигации:
1.	Просмотр авторов (Browse)
2.	Поиск авторов (Search)
3.	Управление авторами (Index)
4.	Создание автора (Create)
5.	Редактирование автора (Edit)
6.	Удаление автора (Delete)
7.	Детали автора с экспортом отчетов (Details)
 
2.1. Просмотр авторов
•	Нажмите кнопку "Просмотр" на карточке "Авторы" на главной странице или выберите "Авторы" в меню "Просмотр и поиск".
•	Откроется страница со списком всех авторов в виде таблицы с возможностью сортировки по различным полям.
Рис. 2 - Страница просмотра авторов. Отображает таблицу со всеми авторами, содержащую поля: Полное имя, Организация, Email, Публикаций, Соавторов, Цитирований, H-индекс, Сред. страниц. Заголовки колонок являются ссылками для сортировки. Доступна кнопка "Поиск и фильтры" для перехода к расширенному поиску.

2.2. Поиск авторов
•	Нажмите кнопку "Поиск" на карточке "Авторы" на главной странице или выберите "Поиск авторов" в меню "Просмотр и поиск".
•	Заполните поля фильтрации: Полное имя, Организация, Email.
•	Нажмите кнопку "Поиск" для применения фильтров.
Рис. 3 - Страница поиска авторов. Содержит форму поиска с полями: Полное имя, Организация, Email. Результаты поиска отображаются в таблице ниже формы с возможностью сортировки по всем полям.

2.3. Управление авторами
•	Выберите "Авторы" в меню "Редактирование" в верхней навигационной панели.
•	Откроется страница управления со списком всех авторов и кнопкой "Создать автора".
Рис. 4 - Страница управления авторами. Отображает таблицу со всеми авторами с полями: ID, Полное имя, Организация, Email, Публикаций. Для каждого автора доступны кнопки "Редактировать" и "Удалить". В верхней части страницы расположена кнопка "Создать автора".

2.4. Создание автора
•	На странице управления авторами нажмите кнопку "Создать автора".
•	Заполните обязательные поля: Полное имя, Организация/Кафедра, Электронная почта.
•	Нажмите кнопку "Сохранить" для создания записи.
Рис. 5 - Страница создания автора. Содержит форму с полями: Полное имя (обязательное), Организация/Кафедра (обязательное), Электронная почта (обязательное). Внизу формы расположены кнопки "Сохранить" и "Отмена".

2.5. Редактирование автора
•	На странице управления авторами нажмите кнопку "Редактировать" напротив нужного автора.
•	Все поля автоматически заполнятся текущими данными автора.
•	Измените необходимые поля.
•	Нажмите кнопку "Сохранить" для сохранения изменений.
Рис. 6 - Страница редактирования автора. Аналогична странице создания, но все поля предзаполнены данными выбранного автора. Позволяет изменить информацию об авторе и сохранить изменения.

2.6. Удаление автора
•	На странице управления авторами нажмите кнопку "Удалить" напротив нужного автора.
•	Откроется страница подтверждения удаления с информацией об авторе.
•	Нажмите кнопку "Удалить" для подтверждения или "Отмена" для отмены операции.
Рис. 7 - Страница удаления автора. Отображает информацию об авторе (Полное имя, Организация, Email) и предупреждение об удалении. Содержит кнопки "Удалить" для подтверждения и "Отмена" для возврата к списку.

2.7. Детали автора и экспорт отчетов
•	На странице просмотра авторов нажмите кнопку "Детали" напротив нужного автора.
•	Откроется страница с детальной информацией об авторе, включая метрики (H-индекс, i10-индекс, Индекс продуктивности) и список публикаций.
•	Для формирования отчета нажмите кнопку "Сформировать отчет".
•	Для экспорта отчета выберите формат: PDF, Word или Excel через соответствующие кнопки.
Рис. 8 - Страница деталей автора. Отображает полную информацию об авторе: основные данные, метрики с подсказками (H-индекс, i10-индекс, Индекс продуктивности), статистику публикаций по типам и годам, список всех публикаций автора. В верхней части доступны кнопки для формирования и экспорта отчетов в различных форматах.

 
3. Работа с публикациями
При выборе раздела "Публикации" доступны следующие функции через меню навигации:
1.	Просмотр публикаций (Browse)
2.	Поиск публикаций (Search)
3.	Управление публикациями (Index)
4.	Создание публикации (Create)
5.	Редактирование публикации (Edit)
6.	Удаление публикации (Delete)
7.	Детали публикации (Details)
 
3.1. Просмотр публикаций
•	Нажмите кнопку "Просмотр" на карточке "Публикации" на главной странице или выберите "Публикации" в меню "Просмотр и поиск".
•	Откроется страница со списком всех публикаций в виде таблицы с возможностью сортировки.
Рис. 9 - Страница просмотра публикаций. Отображает таблицу со всеми публикациями, содержащую поля: Название, Дата публикации, Тип, Страниц, Цитирования, Авторы. Заголовки колонок являются ссылками для сортировки. Доступна кнопка "Поиск и фильтры" для перехода к расширенному поиску.

3.2. Поиск публикаций
•	Нажмите кнопку "Поиск" на карточке "Публикации" на главной странице или выберите "Поиск публикаций" в меню "Просмотр и поиск".
•	Заполните поля фильтрации: Название, Дата от, Дата до, Источник.
•	Нажмите кнопку "Поиск" для применения фильтров.
Рис. 10 - Страница поиска публикаций. Содержит форму поиска с полями: Название, Дата от, Дата до, Источник (выпадающий список). Результаты поиска отображаются в таблице ниже формы с возможностью сортировки по всем полям.

3.3. Управление публикациями
•	Выберите "Публикации" в меню "Редактирование" в верхней навигационной панели.
•	Откроется страница управления со списком всех публикаций и кнопкой "Создать публикацию".
Рис. 11 - Страница управления публикациями. Отображает таблицу со всеми публикациями с полями: ID, Название, Дата публикации, Тип публикации, Источник. Для каждой публикации доступны кнопки "Редактировать" и "Удалить". В верхней части страницы расположена кнопка "Создать публикацию".

3.4. Создание публикации
•	На странице управления публикациями нажмите кнопку "Создать публикацию".
•	Заполните обязательные поля: Название, Тип публикации, Источник, выберите авторов.
•	Заполните дополнительные поля: Дата публикации, Количество страниц, DOI, Аннотация, Ключевые слова, Количество цитирований.
•	Нажмите кнопку "Сохранить" для создания записи.
Рис. 12 - Страница создания публикации. Содержит форму с полями: Название (обязательное), Дата публикации, Тип публикации (обязательное), Источник (обязательное, выпадающий список), Авторы (обязательное, множественный выбор), Количество страниц, DOI, Аннотация, Ключевые слова, Количество цитирований. Внизу формы расположены кнопки "Сохранить" и "Отмена".

3.5. Редактирование публикации
•	На странице управления публикациями нажмите кнопку "Редактировать" напротив нужной публикации.
•	Все поля автоматически заполнятся текущими данными публикации.
•	Измените необходимые поля.
•	Нажмите кнопку "Сохранить" для сохранения изменений.
Рис. 13 - Страница редактирования публикации. Аналогична странице создания, но все поля предзаполнены данными выбранной публикации. Позволяет изменить информацию о публикации, включая список авторов, и сохранить изменения.

3.6. Удаление публикации
•	На странице управления публикациями нажмите кнопку "Удалить" напротив нужной публикации.
•	Откроется страница подтверждения удаления с информацией о публикации.
•	Нажмите кнопку "Удалить" для подтверждения или "Отмена" для отмены операции.
Рис. 14 - Страница удаления публикации. Отображает информацию о публикации (Название, Дата публикации, Тип, Авторы) и предупреждение об удалении. Содержит кнопки "Удалить" для подтверждения и "Отмена" для возврата к списку.

3.7. Детали публикации
•	На странице просмотра публикаций нажмите кнопку "Детали" напротив нужной публикации.
•	Откроется страница с детальной информацией о публикации, включая полный список авторов с их вкладом.
Рис. 15 - Страница деталей публикации. Отображает полную информацию о публикации: основные данные (название, дата, тип, источник, DOI, страницы, цитирования), аннотацию, ключевые слова, список всех авторов с указанием их вклада в публикацию.

5. Навигация и меню
Приложение содержит верхнюю навигационную панель с двумя основными разделами:
•	Просмотр и поиск - содержит ссылки на страницы просмотра и поиска для всех сущностей
•	Редактирование - содержит ссылки на страницы управления для всех сущностей
Рис. 23 - Навигационная панель. Расположена в верхней части страницы, содержит название приложения слева и два выпадающих меню: "Просмотр и поиск" (Авторы, Публикации, Источники, Поиск авторов, Поиск публикаций, Поиск источников) и "Редактирование" (Авторы, Публикации, Источники).

 
6. Диалоговые окна и уведомления
1.	При успешном создании, редактировании или удалении записей (авторов, публикаций, источников) отображается уведомление об успешной операции в правом верхнем углу экрана.
Рис. 24 - Уведомление об успешной операции. Отображается в виде зеленого блока в правом верхнем углу экрана с сообщением об успешном выполнении действия (создание, редактирование, удаление). Содержит кнопку закрытия.

2.	При возникновении ошибок (например, при попытке создать запись с невалидными данными) отображается уведомление об ошибке красного цвета.
Рис. 25 - Уведомление об ошибке. Отображается в виде красного блока в правом верхнем углу экрана с сообщением об ошибке. Содержит кнопку закрытия.

3.	Если какое-либо обязательное поле не заполнено, форма не будет отправлена до тех пор, пока не будут исправлены ошибки валидации. Ошибки отображаются под соответствующими полями формы.
Рис. 26 - Валидация формы. При попытке сохранить форму с незаполненными обязательными полями или неверными данными, под соответствующими полями отображаются сообщения об ошибках красного цвета. Форма не будет отправлена до исправления всех ошибок.

4.	При экспорте отчетов авторов файлы автоматически загружаются в браузер в выбранном формате (PDF, Word, Excel).
Рис. 27 - Экспорт отчета. После нажатия кнопки экспорта отчета автора в выбранном формате (PDF, Word, Excel) файл автоматически загружается через браузер. Имя файла содержит информацию об авторе и дате формирования отчета.

 
7. Инициализация тестовых данных
В правом нижнем углу каждой страницы расположена незаметная кнопка с символом шестеренки (⚙) для инициализации тестовых данных.
•	Наведите курсор на кнопку в правом нижнем углу страницы.
•	Нажмите на кнопку для открытия диалогового окна.
•	Выберите действие: "Создать тестовые данные" или "Удалить все данные из базы данных".
•	Подтвердите действие.
Рис. 28 - Диалог инициализации тестовых данных. Модальное окно с заголовком "Инициализация тестовых данных" содержит три кнопки: "Создать тестовые данные" (создает набор тестовых авторов, публикаций и источников), "Удалить все данные из базы данных" (удаляет все записи), "Отмена" (закрывает окно без действий).
