# UI тесты

UI тесты проверяют работу веб-интерфейса через HTTP запросы и автоматизацию браузера.

## Типы UI тестов

### HTTP интеграционные тесты (WebApplicationFactory)

Используют `WebApplicationFactory<Program>` для создания тестового сервера и проверки HTTP ответов.

**Файлы:**
- `AuthorControllerTests.cs` - тесты контроллера авторов
- `PublicationControllerTests.cs` - тесты контроллера публикаций
- `SourceControllerTests.cs` - тесты контроллера источников
- `TestDataControllerTests.cs` - тесты контроллера тестовых данных
- `IntegrationTests.cs` - интеграционные тесты навигации
- `ContentTests.cs` - проверка содержимого страниц
- `HomePageTests.cs` - тесты главной страницы
- `AuthorTests.cs` - базовые тесты страниц авторов
- `PublicationTests.cs` - базовые тесты страниц публикаций

### Браузерные тесты (FlaUI)

Используют FlaUI для автоматизации браузера и проверки загрузки страниц.

**Файлы:**
- `FlaUIWebTests.cs` - автоматизация браузера

## Покрытие

- ✅ Доступность всех страниц
- ✅ Сортировка по всем полям
- ✅ Поиск и фильтрация
- ✅ CRUD операции
- ✅ Экспорт отчетов (PDF, Word, Excel)
- ✅ Навигация между страницами
- ✅ Проверка содержимого страниц

## Запуск FlaUI тестов

FlaUI тесты требуют:
1. Запущенное приложение (на localhost:7208 или другой порт)
2. Запущенный браузер (Edge или Chrome)
3. Переменная окружения `TEST_BASE_URL` (опционально) для настройки URL
