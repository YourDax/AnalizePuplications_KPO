# Модульные тесты

Модульные тесты проверяют бизнес-логику изолированно от базы данных и веб-интерфейса, используя моки (Moq) для зависимостей.

## Тестируемые компоненты

### AuthorLogicTests
- ✅ Чтение списка авторов (с фильтрами и без)
- ✅ Чтение отдельного автора
- ✅ Создание автора (с валидацией)
- ✅ Обновление автора
- ✅ Удаление автора
- ✅ Проверка дубликатов имен

### PublicationLogicTests
- ✅ Чтение списка публикаций
- ✅ Чтение отдельной публикации
- ✅ Создание публикации (с валидацией авторов)
- ✅ Обновление публикации
- ✅ Удаление публикации
- ✅ Получение публикаций по автору

### SourceLogicTests
- ✅ Чтение списка источников
- ✅ Чтение отдельного источника
- ✅ Создание источника (с валидацией URL)
- ✅ Обновление источника
- ✅ Удаление источника

## Особенности

- Используют Moq для мокирования зависимостей (IAuthorStorage, IPublicationStorage, ISourceStorage)
- Не требуют базы данных
- Быстро выполняются
- Проверяют бизнес-логику и валидацию
